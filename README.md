# AI-News-Summary-Every-Morning
We’ve built a powerful n8n workflow called “Get AI News Summary Every Morning through Gmail” — an intelligent automation that keeps you updated with the latest AI, tech, and world news delivered directly to your inbox every morning. ☕📨

This project automates the process of collecting and summarizing **AI, Tech, and World News** daily using **n8n**.  
Every morning, you’ll receive a neatly summarized report directly in your Gmail inbox — powered by AI automation.

---

## ✨ Key Features

- 🕒 **Automated Scheduling** – Triggers automatically every morning.  
- 🤖 **AI Summary Agent** – Uses **Google Gemini Chat Model** to generate short, meaningful summaries.  
- 🌍 **Multi-Source Feeds** – Collects updates from AI, Tech, and World News feeds.  
- 📧 **Gmail Integration** – Sends a clean and professional summary email daily.  

---

## 🧩 Workflow Overview

1. **Schedule Trigger** — Starts the workflow every morning.  
2. **Get Tech News, World News & AI News** — Fetches articles from multiple RSS feeds.  
3. **AI Summary Agent** — Summarizes all collected articles using Gemini.  
4. **Output Node** — Prepares a concise email-ready summary.  
5. **Send with Gmail** — Automatically sends the email summary to your inbox.  

---

## ⚙️ How to Use

1. Import this workflow into your **n8n** instance.  
2. Connect your **Gmail credentials** securely.  
3. Update or replace RSS sources as needed.  
4. Adjust the **Schedule Trigger** (e.g., every morning at 8 AM).  
5. Execute and enjoy daily AI-powered news in your inbox!
